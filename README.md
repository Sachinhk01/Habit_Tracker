# Habit Tracker (React + Vite, frontend only)

Run locally:
    npm install
    npm run dev

Build for deployment:
    npm run build      # output in dist/

Deploy: upload the dist/ folder to Netlify, or import the repo into Vercel
(build command: npm run build, output directory: dist).
Data is saved in the browser (localStorage).
